# 🎹 JS Piano Synth

A simple, interactive one-octave piano built with Vanilla JavaScript and the Web Audio API. Created as a web development course project.

## 📹 Demo


## ✨ Features
* Playable using your computer keyboard.
* Real-time sound synthesis using the Web Audio API.
* Built purely with HTML, CSS, and Vanilla JS (no frameworks).

## 🚀 How to Run
No installation needed! Just clone the repo and open `index.html` in your web browser to start playing.
